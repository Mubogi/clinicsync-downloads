## Install notes

**Android.** Tap the `.apk`, then allow "Install unknown apps" for your browser
or file manager if Android asks. If you see "Error parsing package", you
downloaded the wrong file — use the release link above, not the source repo.

**Windows.** Run the `.exe` installer.

**Linux.** AppImage: `chmod +x ClinicSync-1.0.4.AppImage` then run it.
Debian/Ubuntu: `sudo apt install ./clinicsync_1.0.4_amd64.deb`.

## Server or Client

On first launch the PC app asks whether this machine is the **Server** (it keeps
the data and other devices connect to it) or a **Client** (it connects to the
Server). It remembers the choice. The Server shows an address like
`http://192.168.1.5:5000` — enter that same address on the phones and other
PCs, which must be on the same Wi-Fi.
